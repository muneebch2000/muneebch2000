## What I’m building

**SecureRAG** explores a practical AI security problem. Two colleagues ask an assistant, *“What did we promise this customer?”* Both can sign in, but only one manages the account. How do we make sure each answer draws only from documents that person can read?

**Twin** is in development at **ESNEXUS**. One design decision I’m working through is when an AI system should suggest a next step and when it needs the user’s permission to act.
